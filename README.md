# Biology Project - Carbon Cycle Model

An interactive web-based 3D model of Earth's Carbon Cycle comparing primitive Earth to present-day Earth, while detailing biological processes such as photosynthesis and cellular respiration.

## Features

- **Interactive 3D Models**: Embedded Spline 3D scenes for Primitive Earth, Present Earth, Photosynthesis, Cellular Respiration, and the Carbon Cycle.
- **Atmospheric Composition Charts**: Dynamic pie charts comparing primitive and present-day atmospheric composition.
- **Dynamic Section Switching**: Switch between five educational modules with synchronized descriptions and diagrams.
- **Responsive Design**: Adapts smoothly across desktop and mobile viewports.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- jQuery
- Chart.js
- Spline 3D Viewer
- ESLint, Prettier, Husky, and `lint-staged`
